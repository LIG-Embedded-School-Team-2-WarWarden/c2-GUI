# 카메라 보정 운용 흐름

이 문서는 카메라 보정 화면의 **수동 수집 단계**와 **검증 자동조준 단계**를 구분하고, 버튼을 눌렀을 때 GUI가 ECS에 보내는 명령을 정리한다.

## 단계 요약

| 단계 | 운용자 동작 | 장치 동작 |
|---|---|---|
| 1. 보정 지점 수집 | 객체를 선택하고 영상 중심까지 방향키로 맞춘 뒤 저장 | 자동조준하지 않음 |
| 2. 다른 위치에서 확인 | 학습에 쓰지 않은 객체를 선택하고 `보정된 각도로 이동` 클릭 | 후보 3D 모델로 자동조준 |
| 3. 결과 적용 | 훈련·검증 오차를 확인하고 `이 보정값 사용하기` 클릭 | 보정값만 저장, 장치는 움직이지 않음 |

첫 단계와 두 번째 단계가 화면상 비슷해 보여도 목적은 다르다. 첫 단계는 모델을 만드는 데이터 수집이고, 두 번째 단계는 그 모델이 새로운 위치에서도 맞는지 확인하는 독립 검증이다.

## 운용 절차

### 1. 시작 조건 확인

- ECS와 FCS가 연결되어 있어야 한다.
- 진행 중인 객체 할당, 수동 촬영, 일괄 촬영, 연속 촬영이 없어야 한다.
- 객체는 정지 상태이며 RDR 관측 목록에 계속 존재해야 한다.

### 2. 수동 보정 지점 수집

1. 장비 설정에서 카메라 방향 맞추기를 연다.
2. 가까운 곳·중간·먼 곳과 좌우·높이가 다른 객체를 선택한다.
3. `이 객체 맞추기`를 누른다.
4. `방향키 조절 켜기`를 누르고 실제 카메라 영상 중심에 객체를 맞춘다.
5. `중심에 맞췄어요 · 저장`을 누른다.
6. 서로 다른 위치를 최소 12개 저장한다. 20~30개를 권장한다.

이 단계에서는 자동조준하지 않는다. 운용자가 맞춘 실제 팬·틸트와 객체의 RDR 상대좌표가 모델의 학습 자료가 된다.

### 3. 검증 자동조준

1. `다음: 다른 객체로 정확도 확인`을 누른다.
2. 수집 단계에서 사용하지 않은 객체를 선택한다.
3. `보정된 각도로 이동`을 누른다.
4. GUI가 객체 기준 정보 `1101`을 읽고 후보 3D 모델로 목표 팬·틸트를 계산한다.
5. 현재 실제각은 `1102`로 읽는다.
6. 차이가 30도를 넘으면 GUI가 여러 구간으로 나눠 `1100`을 보낸다. ECS는 각 명령을 FCS `EF03`으로 전달한다.
7. 각 구간마다 `1102` 실제각이 목표의 0.15도 이내에 들어올 때까지 기다린다.
8. 도착 후 0.1도 미세조정이 자동으로 활성화된다. 영상에서 맞으면 바로 저장하고, 빗나갔으면 방향키로 보정한 뒤 저장한다.
9. 학습에 쓰지 않은 위치를 최소 6개 확인한다.

계산된 목표각과 현재각이 이미 팬·틸트 각각 0.15도 이내라면 `1100`을 보내지 않고 바로 미세조정 단계로 넘어간다.

### 4. 결과 적용

1. 훈련 오차, 별도 검증 오차, 최대 오차와 위치 분포를 확인한다.
2. 적용 가능 조건을 만족하면 `이 보정값 사용하기`를 누른다.
3. GUI는 translation과 rotation을 임시 저장한 뒤 하나의 commit으로 확정한다.
4. 적용 자체는 카메라를 움직이지 않는다. 이후 일반 객체 조준부터 새 3D 보정과 각도 미세조정값이 함께 사용된다.

## 설치 위치가 바뀌는 경우

- 지점은 RDR 기준 상대좌표로 저장되므로 RDR/FCS의 절대 설치 좌표가 바뀌어도 이전 작업을 이어갈 수 있다.
- 저장 형식 1·2의 기존 절대좌표 자료는 불러올 때 RDR 상대좌표로 변환한다.
- RDR과 카메라 사이의 실제 장착 거리 또는 방향이 바뀌면 기존 모델은 유효하지 않으므로 새로 수집해야 한다.

## 자동조준이 보이지 않을 때

| 증상 | 확인 사항 |
|---|---|
| 버튼 이름이 `이 객체 맞추기`임 | 아직 수집 단계다. 12개 이상 저장하고 다음 단계로 이동한다. |
| `1101`만 기록되고 `1100`이 없음 | 목표각과 현재각이 0.15도 이내인지 상태 문구를 확인한다. |
| `device_busy` | 객체 할당이나 다른 촬영 시퀀스를 먼저 종료한다. |
| `target_pending` | 선택 객체가 현재 RDR 관측에 없거나 주사 상태가 아니다. |
| 이동 중 중단됨 | 객체 위치 5cm 초과 변화, 연결 끊김, 창 전환·Esc, 구간 도착 20초 초과를 확인한다. |
| 소스와 화면 동작이 다름 | 실행 중인 Debug GUI를 종료하고 본 프로젝트를 다시 빌드한다. |

## 명령 대응표

| GUI 명령 | ECS/FCS 처리 |
|---|---|
| `1100 CalibrationPoint` | ECS가 FCS `EF03`으로 팬·틸트 이동 |
| `1101 CalibrationReference` | 선택 객체의 보정 기준각 반환 |
| `1102 CalibrationFeedback` | FCS 실제 팬·틸트 반환 |
| `1110/1111` | 현재 3D 이동·회전값 읽기 |
| `1112/1113/1114` | 새 3D 이동·회전값 stage 후 commit |

## GUI 회귀시험

```powershell
dotnet build .\AadcCommandCenter.csproj -c Debug
dotnet run --project .\tests\calibration\CalibrationChecks.csproj -c Debug
```

보정 시험은 자동조준 명령이 실제 후보 각도까지 여러 구간으로 발생하는지, 각 구간이 30도를 넘지 않는지, 도착 후 미세조정이 활성화되는지, 자동조준 중단 시 저장 자료가 변하지 않는지를 검증한다.
