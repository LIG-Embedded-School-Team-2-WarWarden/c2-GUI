# 대공방어 통제 시스템 (WPF)

## 공유 메모리 프레임 수신

WPF는 C++ `Frame`을 named shared memory에서 읽습니다. `control_mock` 송신 프로그램과 동일하게 매핑 이름 `Local\ControlStationMock.SharedMemory.v1`, 뮤텍스 이름 `Local\ControlStationMock.SharedMemory.Mutex.v1`을 사용합니다. 다른 이름을 쓸 때는 `AADC9_SHARED_MEMORY_NAME`과 `AADC9_SHARED_MEMORY_MUTEX_NAME` 환경 변수를 지정합니다.

수신기는 50ms마다 송신 뮤텍스를 획득한 뒤 464바이트 프레임을 읽고 magic(`0x314D4354`), version(1), 구조체 크기, FNV-1a payload 체크섬, 자산 및 표적 개수를 확인합니다. C# 구조체는 `Pack=4`이며 공유 메모리는 읽기 전용으로 엽니다. 현재 용량은 RDR 1개, FCS 1개, 표적 10개입니다. 용량을 변경할 때는 C++과 C#의 상수 및 구조체 크기를 함께 갱신해야 합니다.

공유 메모리 프레임은 레이더·표적·자산의 텔레메트리 전용입니다. 할당, 할당 취소, 발사 명령은 아래 Named Pipe 프로토콜로 별도 전송합니다.

## Named Pipe 명령 통신

WPF는 Named Pipe 클라이언트이고, `EcsMockControlStation`의 C++ 프로그램은 Named Pipe 서버입니다. WPF가 요청을 보내면 같은 연결로 서버가 응답합니다. 서버는 상태를 WPF에 먼저 보내지 않으며, WPF가 1초 간격으로 상태를 조회합니다.

- Pipe 이름: `ECS_NamedPipe`
- 프로토콜 Magic: `0x50495045`
- 프로토콜 버전: `2`
- 요청 구조체: `Pack = 4`, 28바이트
- 응답 구조체: `Pack = 4`, 40바이트
- 명령: 상태 조회, 표적 할당, 할당 취소, 발사

명령 서버는 현재 한 개의 WPF 클라이언트 연결을 처리합니다. 동일한 Pipe 이름으로 모의 통제소를 두 개 실행하면 한 인스턴스만 Pipe를 열 수 있습니다. 오류 231은 이미 다른 서버가 해당 Pipe를 사용 중이라는 뜻입니다.

### C++ 모의 통제소 실행

1. Visual Studio C++ 빌드 도구가 설치되어 있는지 확인합니다.
2. `EcsMockControlStation\BuildEcsMockControlStation.cmd`를 실행합니다. 스크립트가 C++ 서버를 빌드한 뒤 같은 콘솔 창에서 서버를 시작합니다.
3. 공유 메모리 송신기와 WPF를 실행합니다. 표적 및 자산 텔레메트리는 공유 메모리 송신기가 제공하므로 별도로 실행해야 합니다.
4. 콘솔의 `[REQ]`는 WPF 요청, `[RES]`는 해당 요청에 대한 응답입니다. WPF를 사용하는 동안 모의 통제소 창을 열어 둡니다.

콘솔에서 `status`, `connected on|off`, `available on|off`, `reset`, `help`를 사용할 수 있습니다. `quit`은 모의 서버를 종료합니다.

### 모의 할당 및 발사 흐름

- 표적 할당 요청을 받으면 서버는 먼저 `ADJUSTING`으로 응답합니다.
- 모의 FCS 조준 시간은 3초입니다. 이후 상태 조회에 `ASSIGNED`로 응답하고 WPF는 `할당 완료`를 표시합니다.
- 할당 완료 전 발사 버튼은 `대기`로 표시되고 사용할 수 없습니다. 할당 완료 후 발사 버튼이 활성화됩니다.
- 발사 요청을 수신하면 모의 서버는 `FireState = 1`로 응답합니다. WPF의 할당 상태는 `발사 완료`가 됩니다.
- 발사 전 레이저 ON은 요구하지 않습니다. 레이저 상태는 공유 메모리 텔레메트리 값으로 계속 표시됩니다.
- 공유 메모리의 표적 상태 코드가 `1`이면 WPF는 표적 상태를 `HIT`로 표시합니다. 모의 Named Pipe 응답은 표적 상태 텔레메트리를 직접 변경하지 않습니다.

## 프로젝트 소개

라이다 센서를 활용한 공중 위협 표적 탐지와 통제소 기반 표적 정보 전시 및 할당 기능을 갖춘 WPF 기반 대공방어 통제 시스템임
탐지 자산과 통제소 및 타격 자산 간의 연동을 고려하여 대공방어 무기체계의 통제 GUI를 구현하는 것을 목표로 함

## 주요 기능

표적 탐지 정보 전시

표적 위치 및 탐지 정보 시각화

표적 정보 수신 및 관리

통제소 기반 표적 할당 화면

발사 명령을 위한 통제 인터페이스

발사대 상태 및 제어 정보 전시
